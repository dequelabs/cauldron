## Examples

### Single Selection

Allows only one tree item to be selected at a time.

```jsx example
function SingleSelectionTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Single Selection Tree View"
      selectionMode="single"
      items={items}
    />
  );
}
```

### Multiple Selection

Allows multiple tree items to be selected at once.

Allows multiple tree items to be selected independently of one another.

```jsx example
function MultipleSelectionTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [
        { id: '2', textValue: 'Project' },
        { id: '3', textValue: 'Notes' }
      ]
    },
    {
      id: '4',
      textValue: 'Photos',
      children: [{ id: '5', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Multiple Selection Tree View"
      selectionMode="multiple"
      defaultExpandedKeys={['1']}
      items={items}
    />
  );
}
```

### Cascading Selection

Set `selectionStrategy="cascade"` (multiple selection only) to link parents and
their children: selecting or deselecting a parent applies to all of its
descendants, and a parent's checkbox reflects its descendants' state — checked
when all are selected, unchecked when none are, and **indeterminate** (a dash)
when only some are selected.

```jsx example
function CascadingTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [
        { id: '2', textValue: 'Project' },
        { id: '3', textValue: 'Notes' }
      ]
    },
    {
      id: '4',
      textValue: 'Photos',
      children: [{ id: '5', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Cascading Tree View"
      selectionMode="multiple"
      selectionStrategy="cascade"
      defaultExpandedKeys={['1']}
      items={items}
    />
  );
}
```

### Exclusive Selection

Set `selectionStrategy="exclusive"` (multiple selection only) when a parent and
its children are mutually exclusive — for example when a parent represents the
aggregate of its children, so selecting both would double-count. Selecting a
node clears its ancestors and descendants, and a parent shows the
**indeterminate** (dash) state while any descendant is selected. Nodes marked
`locked` are rendered disabled and cannot be selected.

```jsx example
function ExclusiveTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'North America',
      children: [
        { id: '2', textValue: 'United States' },
        { id: '3', textValue: 'Canada' },
        { id: '4', textValue: 'Mexico', locked: true }
      ]
    }
  ];
  return (
    <TreeView
      aria-label="Exclusive Tree View"
      selectionMode="multiple"
      selectionStrategy="exclusive"
      defaultExpandedKeys={['1']}
      items={items}
    />
  );
}
```

### Default Expanded

Pass keys into the `defaultExpandedKeys` prop array to expand them by default.

```jsx example
function DefaultExpandedTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    },
    {
      id: '5',
      textValue: 'More Photos',
      children: [
        { id: '6', textValue: 'Another Image 1' },
        { id: '7', textValue: 'Another Image 2' },
        {
          id: '8',
          textValue: 'Another Image 3',
          children: [{ id: '9', textValue: 'Another Image 4' }]
        }
      ]
    }
  ];
  return (
    <TreeView
      aria-label="None Selection Tree View"
      defaultExpandedKeys={['1', '5', '8']}
      items={items}
    />
  );
}
```

### Labelled by External Element

Use `aria-labelledby` when a visible heading or label for the tree already exists on the page.

```jsx example
function LabelledByTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    }
  ];
  return (
    <>
      <h3 id="file-browser-label">File Browser</h3>
      <TreeView aria-labelledby="file-browser-label" items={items} />
    </>
  );
}
```

### Custom onAction

TreeView with a custom action handler for item selection.

```jsx example
function ActionTreeView() {
  const onAction = (key) => {
    alert(`Selected item: ${key}`);
  };
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Tree View with Action Handler"
      selectionMode="single"
      onAction={onAction}
      items={items}
    />
  );
}
```
