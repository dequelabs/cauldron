## Examples

### Single Selection

Allows only one tree item to be selected at a time.

```jsx example
function SingleSelectionTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Single Selection Tree View"
      selectionMode="single"
      items={items}
    />
  );
}
```

### Cascading Selection

In `multiple` selection mode, `cascadeSelect` and `cascadeDeselect` link a
parent's checkbox to its children. They are independent: enable
`cascadeSelect` so checking a parent checks all of its (non-disabled) children,
and/or `cascadeDeselect` so unchecking a parent unchecks all of its children.
A parent's own checked state is never derived from its children (there is no
indeterminate state). Nodes with `disabled: true` are rendered disabled and are
skipped by cascading selection.

```jsx example
function CascadingTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [
        { id: '2', textValue: 'Project' },
        { id: '3', textValue: 'Notes' },
        { id: '4', textValue: 'Archive (locked)', disabled: true }
      ]
    },
    {
      id: '5',
      textValue: 'Photos',
      children: [{ id: '6', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Cascading Tree View"
      selectionMode="multiple"
      cascadeSelect
      cascadeDeselect
      defaultExpandedKeys={['1']}
      items={items}
    />
  );
}
```

### Virtualized (Long Lists)

Set `virtualized` (with a `height`) to turn the tree into a fixed-height scroll
region that only renders the rows currently in view. This keeps selection
changes fast on long lists, where rendering every row would otherwise make each
click take a long time while appearing to freeze. Omit `virtualized` for the
default behavior, where the tree grows to fit all rows.

Prefer a relative `height` such as `"20rem"`: a pixel height keeps the viewport
fixed while the text inside grows, so a zoomed-in user sees fewer rows.

This mode depends on styles shipped in `@deque/cauldron-styles`, so upgrade it
alongside `@deque/cauldron-react` — an older stylesheet lays the rows out
incorrectly.

Because virtualization removes off-screen rows from the DOM, be aware of these
current limitations when you enable it:

- **Browser find-in-page (Cmd/Ctrl+F) only matches rendered rows.** Rows that
  are scrolled out of view are not in the DOM, so the browser cannot find text
  in them. `TreeView` does not yet expose a search/filter prop as a replacement.
- **No programmatic scroll-to / reveal-node API yet**, so a consumer cannot
  currently scroll a specific off-screen node into view.
- **`aria-rowindex` is not set on rows.** In virtualized mode the treegrid
  reports `aria-rowcount` for the full list, and each row keeps a correct
  `aria-level` / `aria-posinset` / `aria-setsize`, but the matching
  `aria-rowindex` is missing. This is a react-aria-components limitation
  (`useTree` sets the virtualized flag but `TreeItem` never forwards it), not
  something the Cauldron wrapper can fix without patching react-aria.
- **No horizontal scrolling.** The list layout pins each row to the width of the
  scroll region, so a deeply indented or long-labelled item is clipped rather
  than reachable by scrolling sideways. The non-virtualized tree scrolls
  horizontally; this mode does not.
- **The tree needs a definite width.** Rows are absolutely positioned, so in a
  container that sizes to its contents (a popover, a table cell, an
  inline-block) the scroll region measures zero and renders no rows. Give the
  tree — or an ancestor — a definite width.

```jsx example
function VirtualizedTreeView() {
  const items = Array.from({ length: 500 }, (_, i) => ({
    id: String(i + 1),
    textValue: `Item ${i + 1}`
  }));
  return (
    <TreeView
      aria-label="Virtualized Tree View"
      selectionMode="multiple"
      virtualized
      height="20rem"
      items={items}
    />
  );
}
```

### Virtualized with Cascade Selection

`virtualized` composes with `cascadeSelect` / `cascadeDeselect`.
Here a single parent has a long list of children: checking the parent selects
every child, and unchecking it deselects them — while only the rows in view are
rendered, so the cascade stays fast no matter how many children there are.

```jsx example
function VirtualizedCascadeTreeView() {
  const items = [
    {
      id: 'parent',
      textValue: 'All Categories',
      children: Array.from({ length: 300 }, (_, i) => ({
        id: String(i + 1),
        textValue: `Category ${i + 1}`
      }))
    }
  ];
  return (
    <TreeView
      aria-label="Virtualized Cascade Tree View"
      selectionMode="multiple"
      cascadeSelect
      cascadeDeselect
      height={320}
      defaultExpandedKeys={['parent']}
      items={items}
    />
  );
}
```

### Labelled by External Element

Use `aria-labelledby` when a visible heading or label for the tree already exists on the page.

```jsx example
function LabelledByTreeView() {
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    }
  ];
  return (
    <>
      <h3 id="file-browser-label">File Browser</h3>
      <TreeView aria-labelledby="file-browser-label" items={items} />
    </>
  );
}
```

### Custom onAction

TreeView with a custom action handler for item selection.

```jsx example
function ActionTreeView() {
  const onAction = (key) => {
    alert(`Selected item: ${key}`);
  };
  const items = [
    {
      id: '1',
      textValue: 'Documents',
      children: [{ id: '2', textValue: 'Project' }]
    },
    {
      id: '3',
      textValue: 'Photos',
      children: [{ id: '4', textValue: 'Image 1' }]
    }
  ];
  return (
    <TreeView
      aria-label="Tree View with Action Handler"
      selectionMode="single"
      onAction={onAction}
      items={items}
    />
  );
}
```
